# 开机卡控制台（PcCard）视觉规范 v1.0

实现端 WinUI 3 / Fluent 深色，禁用 Mica/Acrylic，软件渲染友好（无大动画、无模糊特效）。窗口 960×680 固定深色主题，全中文。

## 1. Design Tokens

### 颜色（深色唯一主题）

| Token | Hex | 用途 |
|---|---|---|
| `--bg` | `#202020` | 窗口背景 |
| `--surface` | `#2B2B2B` | 卡片/表面 |
| `--surface-2` | `#323232` | 卡片内嵌行 hover / 输入框底 |
| `--border` | `#3D3D3D` | 卡片描边、分隔线（1px） |
| `--text` | `#FFFFFF` | 一级文字 |
| `--text-2` | `#C5C5C5` | 二级文字（对 surface 实测 8.2:1） |
| `--text-3` | `#8B8B8B` | 三级文字/占位（对 bg 实测 4.8:1） |
| `--accent` | `#017D7B` | 品牌青绿：填充按钮、开关开启态、在线强调（对白字实测 5.0:1） |
| `--accent-hover` | `#0E958F` | accent 悬停 |
| `--accent-pressed` | `#016B69` | accent 按下 |
| `--accent-text` | `#2BB5AD` | 青绿的文字化变体：大状态字、强调数字（对 surface 实测 5.6:1） |
| `--off` | `#8494A0` | 关机灰（文字化，由米家 #707E87 提亮以保 3:1 大字对比度） |
| `--success` | `#4CCB5F` | 成功、在线圆点 |
| `--warning` | `#FFB84D` | 警告、卡片离线 |
| `--danger` | `#F47067` | 失败结果、删除按钮悬停 |
| `--on-accent` | `#FFFFFF` | accent 填充上的文字 |

### 圆角 / 间距 / 字体

- 圆角：`--r-sm: 4px`（按钮/输入/开关）、`--r-md: 8px`（卡片）、`--r-pill: 999px`（圆点/结果胶囊）。
- 间距 4px 网格：4 / 8 / 12 / 16 / 20 / 24 / 32。卡片内边距 16–20，区块间距 12。
- 字号/字重：12 regular（辅助）、13 regular（正文/日志）、14 semibold（区块标题）、15 semibold（设备名）、20 semibold（页标题）、34 bold（状态大字）。
- 字体栈：`"Segoe UI Variable Text", "Microsoft YaHei UI", "微软雅黑", sans-serif`；日志时间用 `Consolas, monospace`。
- 焦点环：2px `--accent-text` 外描边 + 1px 内衬；仅 `:focus-visible`。

## 2. 布局度量（960×680）

标题栏 40px（自定义，左图标 20px + 应用名 13px，右系统三键 46×40 each）。内容区 padding 20px，纵向 flex，gap 12px。

| 区块 | 高度 | 说明 |
|---|---|---|
| ① 状态卡 | 118px | surface 卡，左右两栏 |
| ② 操作区 | 56px | 两个大按钮等宽，gap 12 |
| ③ 定时任务卡 | ≈190px | 头行 36px + 行高 44px ×3 |
| ④ 日志卡 | 弹性伸展（≥140px） | 头行 32px + 行高 28px，溢出滚动 |
| ⑤ 底部栏 | 24px | 左右分布 |

**① 状态卡内部**：左栏 = 行1「设备名 15px semibold + 在线圆点 8px + 在线文字 12px 二级」；行2「状态大字 34px bold」；行3「次要信息 12px 三级（运行时长 / 上次开关机时间）」。右栏靠右 = 设备下拉 224×32 + 刷新按钮 32×32，垂直居中。

## 3. 组件状态规格

### 大操作按钮（高 56，圆角 4，字号 15 semibold，gap 8 图标+文字）
| 态 | 视觉 |
|---|---|
| 可用（当前可执行的那个） | 底 `--accent`，字 `--on-accent`；hover 底 `--accent-hover`；pressed 底 `--accent-pressed`；焦点环 |
| 不可用（当前状态下无意义） | 底 `--surface-2`，字 `--text-3`，无 hover，禁焦点 |
| 进行中 | 底 `--accent` 60% 透明，左侧 16px 转圈（细环，600ms 线性旋转，软件渲染可承受的唯一动效），文字「正在开机…」，禁点击 |
| disabled（卡片离线） | 同不可用态，鼠标禁指 |

### 常规按钮（高 32）/ 输入与下拉（高 32）
底 `--surface-2`，1px `--border`，hover 底 `#3A3A3A`；下拉右侧 chevron 12px。

### 在线/离线圆点（8px，pill）
在线 `--success`；离线 `--warning`；未知 `--text-3`。无呼吸动画（软件渲染），靠颜色区分，旁边必配文字标签（不单独依赖色相）。

### 任务行（高 44）
[开关 40×20] [名称 14px] flex-1 · [触发规则 12px 二级] · [上次结果胶囊 12px：成功=success 文字，失败=danger 文字 + 原因] · [删除图标钮 28×28，默认三级字 ×，hover 底 `#F470671F` 字 `--danger`]。

### 开关（ToggleSwitch 40×20）
开：轨 `--accent`，钮白；关：轨透明 1.5px `--text-3` 描边，钮 `--text-3`。

### 日志行（高 28，13px）
`时间（Consolas 12px 三级） | 来源标签（手动/定时，12px 二级） | 动作 | 结果（成功 success / 失败 danger + 简短原因）`。斑马纹不用；行间 1px `#2F2F2F` 分隔。空态：居中「暂无日志」三级字。

## 4. 三种全局状态视觉差异

| | 开机 | 关机 | 卡片离线 |
|---|---|---|---|
| 状态大字 | `已开机`，`--accent-text` | `已关机`，`--off` | `状态未知`，`--text-3` |
| 圆点 | 绿「在线」 | 绿「在线」 | 琥珀「卡片离线」 |
| 卡片左缘 | 3px `--accent` 竖条 | 3px `#5A6670` 竖条 | 3px `--warning` 竖条 |
| 主按钮 | 「开机」置灰，「关机」accent 可用 | 「关机」置灰，「开机」accent 可用 | 两键全禁 + 卡内警告行「开机卡离线，请检查网络后刷新」（warning 色） |
| 次要信息行 | 已运行时长 | 上次关机时间 | 上次同步时间 |

规则：当前状态下**可执行的那个动作**独占 accent 填充，保证任何时刻主视觉焦点唯一。

## 6. 附录：操作区扩展（2026-10-11，用户要求）

操作区从「双键」扩为「**开机 | 关机 | 重启 | ☐强制**」：

- 三键等宽（56 高，同 §3 大按钮规格）；「强制」CheckBox 靠右垂直居中
- 勾选「强制」→ 按钮文案实时变为「强制关机 / 强制重启」（写 `piid5` 的 3/2 档）
- 可用性规则不变：已开机 → 关机/重启可用；已关机 → 开机可用；卡片离线 → 全禁
- 三键同用主色填充（无需维持"双键互斥焦点"的原规则；禁止态仍是静音外观）
- 定时任务对话框同步支持 重启 + 强制勾选

## 7. 附录：动作后置禁用（2026-10-16，用户要求）

- 点击任一动作键后，**三个主键立即全部禁用**（静音外观即为"状态变化"的视觉反馈），页脚提示「已发送『XX』指令 · 等待状态更新…（最长 Ns）」
- 下一次刷新确认状态与期望一致（开机→已开机 / 关机→已关机）后解锁，页脚留存 30 秒「已确认完成」；重启类无云端状态信号 → 固定 60 秒解锁
- 兜底：云侧一直未确认（含卡片离线）→ 120 秒（重启 90 秒）后强制解锁并警示
- 动因：`piid1` 是"按键动作"语义，连点 = 连按电源键（会打断刚启动的机器）——禁用窗口是硬性保护，不只是视觉优化
- 启动/每次刷新自动从云端同步设备列表与名称（`SyncFromCloud`）
